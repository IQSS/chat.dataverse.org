# chat.dataverse.org 

https://chat.dataverse.org describes how current and potential Dataverse users and developers can chat with each other.

This git repo contains the static site (index.html, hosted on GitHub pages) as well as code, docs, and metrics for previous chat solutions (i.e. IRC, Matrix, etc.).

Here we document some details about the current chat service, which is Zulip.

## Zulip

Our Zulip instance can be found at https://dataverse.zulipchat.com

### How to create a Zulip channel

First, do you really need a whole channel? Take the yearly community meetings, for example. So far we've gotten by with a topic per year like this:

- [#Dataverse2027](https://dataverse.zulipchat.com/#narrow/channel/375707-community/topic/.23Dataverse2027/with/629311864)
- [#Dataverse2026](https://dataverse.zulipchat.com/#narrow/channel/375707-community/topic/.23Dataverse2026/with/631985380)
- [#Dataverse2025](https://dataverse.zulipchat.com/#narrow/channel/375707-community/topic/.23Dataverse2025/with/566743905)
- [#Dataverse2024](https://dataverse.zulipchat.com/#narrow/channel/375707-community/topic/.23Dataverse2024/with/437879212)

If possible, simply create a topic instead instead of a channel, probably under [#community](https://dataverse.zulipchat.com/#narrow/channel/375707-community).

If you definitely want a channel, here are the steps:

1. Generally, follow https://zulip.com/help/create-a-channel
1. Under "Who can access this channel", select "Web-public" (for transparency).
1. Check the box for "Default channel for new users".
1. Click "Continue to add subscribers" and then make everyone subscriber. They can unsubscribe later if they wish.
